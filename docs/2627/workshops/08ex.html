Where do the \(\pm 1.96\) multipliers come from?

Question 1

The code below gives us the means from lots and lots of samples. Last week we saw this used to get estimated means from 1000 samples, but this week we’ll up it to 10000! We will also use a sample size of \(n = 47\), which is the number of responses to the DAPR1 class survey, so each of the 10000 means is the mean of a different sample of 47 students.

means47 <- replicate(10000, mean(rnorm(n = 47, mean = 15, sd = 25)))
Tipreminder/breakdown of how the code works

This bit of code takes a sample of size 47, from a distribution that has a mean of 15 and a standard deviation of 25.
It gives 47 numbers — in our example, each one of them is the “outlook” score for a person.

rnorm(n = 47, mean = 15, sd = 25)

Wrapping the whole bit inside mean() makes it so that instead of returning all 47 scores in the sample, it returns just the mean of the 47 scores

mean( rnorm(n = 47, mean = 15, sd = 25) )

Finally, the function replicate() is used to “run code X times”. In this case, we’re running the mean(rnorm(...)) bit of code 10000 times. Each time, it takes a sample of 47 people’s scores and returns the estimated mean. So we get back 10000 means.

replicate(10000, mean( rnorm(n = 47, mean = 15, sd = 25) ) )

Finally, means47 <- stores those 10000 means into an object called means47.

Because means47 is a vector (it just has one dimension), if we want to find the 10th entry, we can use <vector name>[<entry-number>] to print it.
(Note, if you do this, you will get a different number, because you have a different set of 10000 samples!)

means47[10]
[1] 11.1

To check if something is a vector, you can run dim(means47). If it returns NULL, then it is a vector with entries. If it returns numbers, then it is a tibble or dataframe with rows and columns.

We also saw how we can create a dataframe object (with rows and columns), by using code such as the below. We’ve added a little extra bit here. Line 4 takes the dataframe created in lines 1-3, and arranges it (i.e. sorts it) in ascending order according to the value in the estimate column. Which means the first row is now the smallest estimate, and the last row (row 10000) is the largest.

data47 <- tibble(
    estimate = means47
  ) |> 
  arrange(estimate)

Create a new column of standardised (or z-scored) estimates.

The number 1.088^{-15} is a very small number, and the notation e-15 means that there are 15 zeros after the decimal point before the first non-zero number. So this is very close to 0 as we would expect.

Question 3

To build a 95% CI we need to find the multipliers that give us the middle 95% in a standard normal distribution.

This is done by finding:

  1. the z-score with an area of 0.025 in the lower tail
  2. the z-score with an area of 0.025 in the upper tail (i.e. an area of 0.975 to the left = 1 - 0.025)

Task: Because the data are already ordered by size of the estimate, and we have 10000 of them, find the multipliers (z-scores) corresponding to the middle 9500 estimates. Extract two rows of the data, one that is the first row of the middle 9500, and one that is the last row of the middle 9500. The value of est_Z for these rows will give us the multiplier for the confidence interval

Bonus– what do you notice about the values of the est_Z column for these rows? They should be close to +/-1.96!

TipHint

If we have 10000 things, then the middle 9500 (= 0.95 * 10000) are between 250 and 9750!

🗂️ See TODO df[r,c] flashcard flash card.

data47[c(250,9750), ]
# A tibble: 2 x 2
  estimate est_Z
     <dbl> <dbl>
1     7.85 -1.96
2    22.2   1.98

The lower multiplier is -1.96 and the upper one is 1.98. As you see, these are close to -1.96 and +1.96, which is what theory expects for a 95% confidence interval. The more samples we take, i.e. if we increased 10000 to even more, the closer these values will get to -1.96 and +1.96.

How do we use the \(\pm 1.96\) multipliers to create a 95% Confidence Interval?

Question 4

Let’s use the multipliers from theory to compute a confidence interval for the mean population outlook score.

Recall the formula for a confidence interval is:

\[\bar{x} \pm 1.96 * SE\]

where \(SE\) is the standard error of the mean and is computed as:

  • \(SE = \frac{\sigma}{\sqrt{n}}\) if you know the population standard deviation \(\sigma\), or
  • \(SE = \frac{s}{\sqrt{n}}\) if you only know the sample standard deviation \(s\).

Read the data from the DAPR1 class survey (https://uoepsy.github.io/data/dapr1_2627_survey.cs), and provide a 95% confidence interval for the mean outlook score using the fact that we know that in the population outlook scores have a standard deviation \(\sigma = 25\).

# Read DAPR1 survey data into R and store into an object called `sdata`
sdata <- read_csv("https://uoepsy.github.io/data/dapr1_2627_survey.csv")

# Only keep the columns representing the participant pseudonym and outlook score
sdata <- sdata|>
  select(pseudonym, outlook)

# Compute sample size (n) and sample mean (xbar)
n <- nrow(sdata)
xbar <- mean(sdata$outlook)

# Compute 95% CI
xbar - (1.96 * 25/sqrt(n))
[1] 17.6
xbar + (1.96 * 25/sqrt(n))
[1] 26.1
