Question 1

This workshop starts off conceptual again. The goal of the first part of this workshop is to show you where we get the \(\pm\) 1.96 multipliers that appear in the formula for a 95% Confidence Interval. Later in the workshop, things get more practical: you’ll use these multipliers to calculate a 95% Confidence Interval for your observed outlook scores.

Last week, you used replicate(), mean() and rnorm() to get estimated means from 1000 random samples from the population of outlook scores that we defined. This week, our exploration will start in a similar way, with a couple modifications.

First, our estimates will be more precise if we have more than 1000 samples, so we’re going to up this to 10,000. Second, we will set a sample size of \(n = 47\), the number of responses to the DAPR1 class survey. Each of the 10,000 means in means47 below is the mean of a different hypothetical sample of 47 students.

Copy and run this code.

means47 <- replicate(10000, mean(rnorm(n = 47, mean = 15, sd = 25)))
TipReminder/breakdown of how this code works

Let’s start with the innermost term:

rnorm(n = 47, mean = 15, sd = 25)

This bit of code takes a sample of size 47 from a normal distribution that has a mean of 15 and a standard deviation of 25.
(These are the parameters that we defined our population to have last week.) The result of rnorm() is a vector of 47 numbers. In our example, each number represents one person’s outlook score.

Next, by wrapping that whole bit inside mean(), we ask R to take the mean of those 47 numbers:

mean( rnorm(n = 47, mean = 15, sd = 25) )

Finally, by wrapping that whole bit inside replicate(), we repeat all of that however many times we want. In this case, we’ll repeat it 10,000 times. Each time, it takes a sample of 47 people’s scores (the rnorm() bit) and then finds their mean (the mean() bit). The result is a vector of 10,000 means.

replicate(10000, mean( rnorm(n = 47, mean = 15, sd = 25) ) )

Finally, means47 <- stores those 10,000 means into an object called means47.

Again, like last week, we want to use this list of numbers as a column of a dataframe. The code below accomplishes this, and does an extra step too: it sorts the values in the estimate column.

Specifically, the arrange() function in Line 4 takes the dataframe created in Lines 1–3 and sorts it in ascending order by the estimate column. After sorting, the first row contains the smallest estimate (i.e., the smallest sample mean), and the final row contains the largest estimate (i.e., the largest sample mean).

Copy and run this code.

data47 <- tibble(
  estimate = means47
) |> 
  arrange(estimate)

Now, answer the following questions:

  • What is the estimate in the 5000th row of data47?
  • Bonus conceptual challenge: Which measure of central tendency is given by the estimate in the 5000th row?

🗂️ See Subset a dataframe > Extract row(s) flash card.

data47 |> slice(5000)

1     15.0

The value that you see in your 5000th row might be different than mine. This is because when we’re drawing random samples, they’ll be a little bit different every time.

Now, as for what measure of central tendency this represents: Because we sorted this dataframe in ascending order and we’re looking at the middle value, 50% of the values will be smaller than the quantity in the 5000th row and 50% of the values will be larger. That means we’re looking at the median of all these sample means!

data47 |>
  summarise(
    median = median(estimate)
  )
# A tibble: 1 × 1
  median
   <dbl>
1   15.0

Question 2

Add a new column to data47 that contains the z-scored version of estimate. Name that column est_z.

Check that the mean of the new column is zero (or at least a very very small number close to zero) and that the SD is 1.

Copy and run the following code to create a density plot of your distribution of z-scores.

data47 |>
  ggplot(aes(x = est_z)) +
  geom_density()

🗂️ See Calculate z-scores flash card.

To create a new column called est_z containing the z-scored version of estimate:

data47 <- data47 |>
  mutate(
    est_z = (estimate - mean(estimate)) / sd(estimate)
  )

To check that it has a mean of 0 and standard deviation of 1:

data47 |> summarise(
    mean_est_z = mean(est_z),
    sd_est_z = sd(est_z)
)
# A tibble: 1 × 2
  mean_est_z sd_est_z
       <dbl>    <dbl>
1  -3.34e-15     1.00

This number –3.34e-15 for the mean is written using scientific notation, which is a way to abbreviate very small or very large numbers. In this case, the number –3.34e-15 is very small: the e-15 bit means that the number contains a 0, a decimal, and then 14 more zeroes before we see the 334: 0.00000000000000334

This is very close to zero, so we are satisfied! (Sometimes R can’t handle actual zeroes, so it approximates zero using tiny tiny numbers like this.)

Finally, here’s the density plot of z-scores. Again, yours might look a little different because of the random sampling.

data47 |>
  ggplot(aes(x = est_z)) +
  geom_density()

Question 3

A 95% confidence interval (CI) contains the middle 95% of a standard normal distribution. In other words, in a standard normal distribution:

  • 2.5% of the probability distribution is below the 95% CI’s lower bound, and
  • 2.5% of the probability distribution is above the 95 CI’s upper bound.

We have approximated a standard normal distribution using these 10,000 z-scores. And we can approximate its 95% CI by taking the middle 9500 z-scores.

Extract two rows from data47:

  • the first row of the middle 9500 estimates, and
  • the last row of the middle 9500 estimates.

Answer: What are the z-scores in those two rows?

TipHint

If we have a list of 10,000 things, then the middle 9500 are between 250 and 9750.

🗂️ See Subset a dataframe > Extract row(s) flash card.

If we have a list of 10,000 things, then the middle 9500 are between 250 and 9750. So we want to look at rows number 250 and 9750.

If you want to get fancy, here’s a way to use slice() and square-bracket indexing to get both of those two rows in one command:

data47 |> slice(c(250, 9750))
# A tibble: 2 × 2
  estimate est_z
     <dbl> <dbl>
1     7.83 -1.96
2    22.2   1.95
data47[c(250,9750), ]
# A tibble: 2 × 2
  estimate est_z
     <dbl> <dbl>
1     7.83 -1.96
2    22.2   1.95


The lower multiplier is -1.96 and the upper one is +1.95.

As you see, these are close to -1.96 and +1.96, which is what theory expects for a 95% confidence interval. That’s cool!!

What this shows us: the multipliers for the 95% CI come from the z-scores that are at the lower and upper bounds of the middle 95% interval of the standard normal distribution.

The more samples we take (that is, if we increased our 10,000 to even more), the closer our z-scores here would get to -1.96 and +1.96.

Question 4

Now things are getting practical again!

Let’s use the \(\pm\) 1.96 multipliers to compute a confidence interval for the mean population outlook score, representing people’s pessimism vs. optimism on a scale from –100 to 100.

The formula for calculating the upper and lower bounds of the 95% confidence interval is

\[\bar{x} \pm 1.96 * SE\]

where \(\bar{x}\) is the sample mean and \(SE\) is the standard error of the mean. \(SE\) is computed as:

  • \(SE = \frac{\sigma}{\sqrt{n}}\) if you know the population standard deviation \(\sigma\), or
  • \(SE = \frac{s}{\sqrt{n}}\) if you only know the sample standard deviation \(s\).

First, read the data from the DAPR1 class survey (https://uoepsy.github.io/data/dapr1_2627_survey.csv).

🗂️ See Read in and inspect data flash card.

Next, using the formula above and our knowledge that the population standard deviation of outlook scores is \(\sigma = 25\): calculate the upper and lower bounds of the 95% confidence interval for the mean outlook score.

# Read DAPR1 survey data into R and store into an object called `sdata`
sdata <- read_csv("https://uoepsy.github.io/data/dapr1_2627_survey.csv")

# Compute sample size (n) and sample mean (xbar)
n <- nrow(sdata)
xbar <- mean(sdata$outlook)

# Compute 95% CI
xbar - (1.96 * 25/sqrt(n))  # lower bound
[1] 17.6
xbar + (1.96 * 25/sqrt(n))  # upper bound
[1] 26.1
