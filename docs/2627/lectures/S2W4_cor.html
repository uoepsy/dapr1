What are correlations?

What are correlations?

If two variables are correlated, then as the value of one variable changes, the value of the other variable changes too.

Put differently: you can make a reasonable guess about the value of one variable based on the value of the other one.


Not correlated:

For any given value of x, you can’t really predict what kind of value y is likely to have.

Positively correlated:

If x increases, then y increases.

If x decreases, then y decreases.

Negatively correlated:

If x increases, then y decreases.

If x decreases, then y increases.

We measure correlation using a
“correlation coefficient” between –1 and 1


Not correlated:

For uncorrelated variables, the correlation coefficient will be close to zero.

Positively correlated:

For positively correlated variables, the correlation coefficient will be between 0 and 1 (that is, positive).

Negatively correlated:

For negatively correlated variables, the correlation coefficient will be between –1 and 0 (that is, negative).

What’s the correlation coefficient for this data?


We find out the correlation coefficient using the function cor(), giving it each column of our data frame.

The format to use in general:

cor(DATA$COLUMN1, DATA$COLUMN2)

For our income/test score data:

cor(ses_data$Income, ses_data$Score)
[1] 0.216


  • Positive correlation coefficient \(\rightarrow\) as income increases, so does SAT score.

  • You can interpret the size of a correlation coefficient kind of like a percentage: 21.6% is kind of small, but definitely not nothing.

    • Weak correlations: between .1 and .3 (whether positive or negative)
    • Moderate correlations: between .3 and .5 (whether positive or negative)
    • Strong correlations: greater than .5 (whether positive or negative)


The specific kind of correlation coefficient that we get from cor() by default is Pearson’s correlation coefficient.

We represent this coefficient as \(r\).

Testing Pearson’s correlation


What we often really want to know: how likely is it that we would get a correlation coefficient like this one if there were no association between income and test scores?

Is the correlation of 0.216 stronger than we would expect if, in reality, the two variables were uncorrelated?


We define our null hypothesis, H0: The Pearson correlation coefficient \(r\) is equal to 0 (that is, the variables are uncorrelated).

\[H_0 : r = 0\]

We also define the alternative hypothesis, H1: The Pearson correlation coefficient \(r\) is not equal to zero (that is, the variables are correlated somehow).

\[H_1 : r \neq 0\]

Run the test


Instead of cor(), use cor.test():

cor.test(ses_data$Income, ses_data$Score)

    Pearson's product-moment correlation

data:  ses_data$Income and ses_data$Score
t = 6, df = 755, p-value = 2e-09

 0.147 0.283

Can we reject the H0 that income and test score are uncorrelated?

Reporting Pearson’s correlation


We found a weak positive correlation between a student’s score on the SAT Verbal test and their parents’ income (Pearson’s \(r\) = .22, \(t\)(755) = 6, \(p\) < .001). This result suggests that being from a higher-income family is associated with higher test scores, while being from a lower-income family is associated with lower test scores.


APA notation format for reporting the key inferential values:

Pearson’s \(r\) = [correlation coefficient], \(t\)([degrees of freedom]) = [t-statistic], \(p\) = [p-value]


However, before writing our report and calling it a day, we need to check the test’s assumptions.

What does Pearson’s correlation require / assume about the data?

What does Pearson’s correlation require / assume about the data?


Data requirements:

Both variables are continuous.

Data contains no extreme outliers.

Assumption of linearity:

The association between the variables is sufficiently linear.

Assumption of independence:

Both variables are normally distributed.

Assumption of independence:

Each variable’s variance is equal across the range of the other variable.


What if one or more of these things isn’t true?

  • Then you shouldn’t use Pearson’s correlation to analyse your data.

  • Instead, you can almost always use Spearman’s correlation, which we’ll talk about in a bit.

Spearman’s correlation

What is Spearman’s correlation?

A more flexible kind of correlation that’s able to handle any variables that represent rankings or orderings.


Pearson’s correlation

  • can only be a straight line.
  • assumes that y changes by the same amount for every increment of x.
Code 
tibble(
  x = -3:3,
  y = x
) |>
  ggplot(aes(x=x, y=y)) +
  geom_point(size = 5) +
  geom_path(linewidth = 1.5) +
  theme(
    axis.ticks = element_blank(),
    axis.text = element_blank()
  )

Spearman’s correlation

  • does not have to be a straight line.
  • only cares about the direction of change, not the amount.
Code 
set.seed(1)
tibble(
  x = -3:3,
  y = x + rnorm(7, mean = 0, sd = 0.5)
) |>
  ggplot(aes(x=x, y=y)) +
  geom_point(size = 5) +
  geom_path(linewidth = 1.5) +
  theme(
    axis.ticks = element_blank(),
    axis.text = element_blank()
  )

But for now: Because Spearman’s correlation is more flexible, it can also handle cases where Pearson’s assumptions weren’t met.

Testing our SES data with
Spearman’s correlation


We saw that Pearson’s correlation coefficient is represented by \(r\).

Spearman’s correlation coefficient is represented by the Greek letter rho, \(\rho\).

Otherwise, hypotheses are defined just the same way!


\[ \begin{align} H_0 &: \rho = 0 \\ H_1 &: \rho \neq 0\\ \end{align} \]

Run the test in R

We can use cor.test() again. We’ll just change the type of correlation by adding method = 'spearman':

cor.test(
  ses_data$Income,
  ses_data$Score,
  method = 'spearman'
)

    Spearman's rank correlation rho

data:  ses_data$Income and ses_data$Score
S = 57826912, p-value = 3e-08
alternative hypothesis: true rho is not equal to 0
sample estimates:
rho 
0.2


Can we reject the H0 that Income and SAT score are uncorrelated?

Reporting Spearman’s correlation (and this whole analysis journey)


We wanted to find out whether students from higher-income families tend to achieve higher test scores than students from lower-income families. However, a Shapiro-Wilk test indicated that our income variable deviated significantly from a normal distribution (\(W\) = 1, \(p\) < .001). We therefore used Spearman’s \(\rho\) instead of Pearson’s \(r\) to test the correlation between income and test score.

We found a weak positive correlation (Spearman’s \(\rho\) = .2, \(p\) < .001). This result suggests that higher family income is significantly associated with higher test scores, and lower family income is associated with lower test scores.


APA notation format for reporting the key inferential values:

Spearman’s \(\rho\) = [correlation coefficient], p = [p-value]

How do we check whether we’re satisfied with each test’s assumptions?

  • Pearson:
    1. check that variable is on interval/ratio scale;

    1. check that variable represents rankings/orderings
