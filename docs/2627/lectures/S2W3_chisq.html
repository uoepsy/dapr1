How can we find out whether ASD+ADHD
co-occur unexpectedly often?

Same idea as always: We take the data we observed and compare it to what we would expect to find, if the effect/difference we care about didn’t exist.

Observed “contingency table”:

Code 
library(stats)
xtabs(~ ADHD + ASD, data = neurotype_data)
         ASD
ADHD      noASD yesASD
  noADHD  61259   1107
  yesADHD  7408   1139

Expected “contingency table”:

Code 
neurotype_chisq <- chisq.test(neurotype_data$ADHD, neurotype_data$ASD)
neurotype_chisq$expected

neurotype_data$ADHD noASD yesASD

            yesADHD  8276    271


Where do the expected counts come from?

Expected counts are essentially fancy averages, calculated on a table of numbers, not a list of numbers.

You do not need to memorise how to calculate them! The working-out is here only in case you’re curious.


\[ \text{expected counts} ~=~ \frac{\text{total counts in row} \times \text{total counts in column}}{\text{sample size}} \]


For example, the expected count for yesADHD and yesASD, based on the counts observed:


         ASD
ADHD      noASD yesASD
  noADHD  61259   1107
  yesADHD  7408   1139

\[ \begin{align} \text{expected counts} &= \frac{(7408 + 1139) \times (1107 + 1139)}{70913} \\[.5em] &= \frac{8547 \times 2246}{70,913} \\[.5em] &= \frac{19,196,562}{70,913} \\[.5em] &= 271 \end{align} \]

If the co-occurrence between ADHD and ASD were only based on how common each neurotype is individually, we would expect them to co-occur in 271 cases.

Instead we observed a co-occurrence in 1139 cases—more than we’d expect. But is it significantly more?

How do we compare observed and expected counts?

How do we compare observed and expected counts?

We use a chi-squared (\(\chi^2\), pronounced “kye”) test!

Specifically: a \(\chi^2\) test of independence, since we’re essentially testing if ASD and ADHD occur independently from one another.


The null and alternative hypotheses that we’re testing:

  • \(H_0\): ASD is independent of ADHD
  • \(H_1\): ASD is not independent of ADHD

(Don’t worry about mathematical notation for these hypotheses!)

The logic of a chi-squared test of independence


The idea is really similar to the t-tests you’re already familiar with!

In a t-test:

The difference between two group means is measured using a t-statistic.

In a \(\chi^2\) test:

The difference between observed and expected counts is measured using a \(\chi^2\) statistic.

To find out if group means differ significantly, we compare the t-statistic to a t-distribution that represents the world in which the true difference between groups means is zero.

To find out if observed and expected counts differ significantly, we compare the \(\chi^2\) statistic to a \(\chi^2\) distribution that represents the world in which the true counts are the expected (independent) counts.

If the t-statistic is far enough into the tails of that distribution, we conclude that our observed data is very unlikely if the true difference between group means were zero; we reject H0.

If the \(\chi^2\)-statistic is far enough into the tails of that distribution, we conclude that our observed data is very unlikely if the true counts were the expected (independent) counts; we reject H0.

The chi-squared distribution

How \(\chi^2\) statistics would be distributed if the true counts were the expected counts
(i.e., if the H0 of independence is true):

Like the t-distribution, the exact shape of the \(\chi^2\) distribution depends on degrees of freedom (df).

For \(\chi^2\), degrees of freedom are based on the size of your contingency table:

\[(\text{number of rows} - 1) \times (\text{number of columns} - 1)\]

Finding p-values

  • We take our observed \(\chi^2\) statistic
  • We compare it to the \(\chi^2\) distribution with appropriate df
  • We see how probable it is to observe a \(\chi^2\) statistic as extreme or more extreme than the one we observed
    • That probability = the area under the distribution to the right of our observed \(\chi^2\) statistic
    • That probability = our test’s p-value

Run the chi-squared test in R

neurotype_chisq <- chisq.test(
  neurotype_data$ADHD,   # name one variable
  neurotype_data$ASD,    # name the other variable (order doesn't matter)
  correct = FALSE        # run the basic version of the test, not "corrected"
)
neurotype_chisq

Can we reject the H0 that ASD and ADHD are independent?

Explore results in more detail

There are lots of different outcomes that are consistent with H1 (that ADHD and ASD are not independent).

How do we find out specifically if ASD and ADHD co-occur more than we would expect?


We can find this out from the \(\chi^2\) test’s residual:

neurotype_chisq$residuals
                   neurotype_data$ASD
neurotype_data$ADHD  noASD yesASD
            noADHD    3.53 -19.54
            yesADHD  -9.54  52.77


  • Negative residuals = counts were lower than expected in that cell.
  • Positive residuals = counts were higher than expected in that cell.


For the mathy among you:

\[ \chi^2 ~ \text{residuals} ~=~ \frac{\text{observed} - \text{expected}}{\text{square root(expected)}} \]

Reporting the chi-squared test


To find out whether occurrence frequencies of ADHD and ASD are independent in children, we performed a \(\chi^2\) test of independence. We found a significant association between ADHD and ASD (\(\chi^2\)(1, N = 70,913) = 3270, p < .001). Therefore, at \(\alpha = .05\), we reject the H0 that ADHD and ASD are independent in children. Specifically, the test’s residuals indicate that ADHD and ASD co-occur in children more frequently than we’d expect.


APA notation format for reporting the key inferential values:

\(\chi^2\)([degrees of freedom], N = [sample size]) = [chi-squared test statistic], \(p\) = [p-value]

What does the chi-squared test require / assume about the data?

What does the chi-squared test require / assume about the data?


Data requirements:

Both variables are categorical.

Expected counts in each cell of the contingency table \(\geq\) 5.

Assumption of independence:

The obtained sample data are a random sample from the population of interest.


What if one or more of these things isn’t true?

  • Then you shouldn’t use a chi-squared test of independence to analyse your data.

  • If expected values are less than 5: use Fisher’s Exact test (not covered in DAPR, you don’t need to know anything more about it).

  • If data aren’t independent: you’ll learn about some statistical machinery in DAPR2/DAPR3 to deal with this.

Calculating the chi-squared statistic (1)

For each cell in the contingency table, calculate:

\[ \frac{\text{(observed minus expected)}^\text{squared}}{\text{expected}} \]

then add all those numbers up. The result is the \(\chi^2\) statistic.

Observed:

     [,1]  [,2] 
[1,] 61259  1107
[2,]  7408  1139

Expected:

      [,1] [,2]
[1,] 60391 1975
[2,]  8276  271


So: (calculation continued on next slide)

noASD yesASD
noADHD \[\frac{(61,259 - 60,391)^2}{60,391}\] \[\frac{(1107-1975)^2}{1975}\]
yesADHD \[\frac{(7408-8276)^2}{8276}\] \[\frac{(1139-271)^2}{271}\]

Calculating the chi-squared statistic (2)

Subtract terms in the numerator to get: (cool how the same number comes out everywhere!)

noASD yesASD
noADHD \[\frac{868^2}{60,391}\] \[\frac{-868^2}{1975}\]
yesADHD \[\frac{-868^2}{8276}\] \[\frac{868^2}{271}\]


Square the numerator to get:

noASD yesASD
noADHD \[\frac{753,935}{60,391}\] \[\frac{753,935}{1975}\]
yesADHD \[\frac{753,935}{8276}\] \[\frac{753,935}{271}\]

Calculating the chi-squared statistic (3)

Divide numerator by denominator to get:

noASD yesASD
noADHD \[12.5\] \[381.7\]
yesADHD \[91.1\] \[2785.1\]


Add up all those numbers:

\[ 12.5 + 381.7 + 91.1 + 2785.1 = 3270 = \chi^2 \text{ statistic} \]
